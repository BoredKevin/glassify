# Glassify

Glassify is a web-based image processing tool that allows users to apply Meta Glasses metadata into their media.

This allows users to users to use the [spin view](https://creators.instagram.com/blog/creator-toolkit-for-ai-glasses) feature on instagram.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/boredkevin/glassify.git
   cd glassify
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

---

## Available Scripts

- `npm run dev` - Start a Vite dev server.
- `npm run build` - Run type-checking (`tsc -b`) and bundle the frontend for production with Vite.
- `npm run preview` - Preview the production build locally.
